# Android Decomp/Recomp Pack

An obtainium pack for native android decompilations and recompilations of classic video games. All games are tested and are confirmed to have working controller support.

Import the pack to get automatic updates for these native source ports straight to your device.

## Getting Started

### 1. Install Obtainium
Download and install the latest release of Obtainium on your Android handheld.

### 2. Import the Pack
1. Download the latest release of the pack.
2. In Obtainium, go to **Import / Export** > **Obtainium Import**.
3. Select the json file you just downloaded.

## FAQ

#### Do I need to provide my own game files?
Yes. These are pure source code ports and recompilations. You will need to provide your own legally acquired game ROMs/assets during the initial setup on your handheld to generate the playable files.
